# Agent instructions

A BB sidebar thread-list plugin: a fork of bb's built-in `thread-list` with an added Inbox tab. Read `docs/brief.md` for the decisions so far.

## Agent skills

### Issue tracker

Track work in GitHub Issues on KaviiSuri/bb-plugin-inbox, using the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the default five-role triage vocabulary. See `docs/agents/triage-labels.md`.

### Domain docs

This repository uses a single-context domain-doc layout. See `docs/agents/domain.md`.
