# A child that asks the human gets its own item

When a `human`-audience child (a grilling child, one that asks a question or wants a permission) needs the human, it becomes its own item, and the row names its parent. The alternative, from T3 Code, shows the child's request on the parent's row instead; the LOGIC prototype (story 2, `prototype/inbox-logic`) showed that makes a still-running parent an item, breaking "a running thread is never an item". The user chose the child's own item.
